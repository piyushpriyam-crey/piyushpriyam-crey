## 👋 About

I'm a software engineer with 7+ years of experience building backend services, REST APIs, microservices, data pipelines, and applied machine learning systems across government, enterprise, and consulting environments.

Currently, I lead full-lifecycle engineering and modernization for provincial digital services at the **Government of Nova Scotia**, working across application architecture, API development, databases, observability, and cloud delivery.

My work spans:

- **Backend engineering:** Python, Django, FastAPI, REST APIs, microservices, SQL optimization
- **AI & machine learning:** RAG, LLM applications, recommendations, forecasting, MLOps
- **Infrastructure:** Docker, Kubernetes, CI/CD, AWS, Azure, GCP, OpenTelemetry
- **Engineering quality:** testing, performance tuning, maintainable architecture, operational reliability

> **Ask me about:** scalable backend architecture, production RAG and LLM applications, hybrid retrieval, SQL and API performance, MLOps, and open-source developer tooling.
